# 🚀 Hero App

## 📌 Description
**Hero App** is a web-based application where popular apps are showcased and managed.  
Users can browse popular apps, install them, and view all installed apps in a dedicated section.  
The app provides a simple and user-friendly interface for managing installed applications.

## 🛠️ Technologies Used
- **React** – Frontend framework
- **HTML** – Markup structure
- **CSS** – Styling and layout

## ✨ Features
- Browse popular apps
- Install apps with one click
- View all installed apps
- Prevent duplicate installations
- Clean and responsive UI
